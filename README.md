# Reminder

## 説明

Reminder は、Kotlin Multiplatform と The Composable Architecture (TCA) を活用したアプリ開発手法を示すサンプルプロジェクトです。
本プロジェクトでは、ビジネスロジックを shared モジュールに実装し、プラットフォーム固有のUIは iOS では SwiftUI と TCA、Android ではネイティブコンポーネントを用いて構築しています。
